Install Python and Tkinter

  1. Open the official Python for Windows downloads page using the button above.
  2. Download and run the current Python 3 installer for your Windows computer.
  3. In the installer’s Optional Features, keep tcl/tk and IDLE selected. This installs the Tk support needed by Tkinter.
  4. Finish the installation. If offered, select Add Python to PATH.
  5. Download ENIGMA-X.pyw above and double-click it to launch. If it does not open, run python ENIGMA-X.pyw from Command Prompt.

Check that Tkinter is installed

Open Command Prompt and run:

python -m tkinter

A small Tk window should appear if Python and Tkinter are ready.

The cipher features work locally. The messenger relay feature additionally requires a separately running enigma_relay.py server. Historical Enigma ciphers are not secure by modern standards; use ENIGMA-X for learning and experimentation, not to protect real secrets.
