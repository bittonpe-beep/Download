Before you run it

  • Requires Python 3 and Tkinter (included with many standard Python installations).
  • Download the file, then double-click it if .pyw files are associated with Python; otherwise run it with Python.
  • The cipher features work locally. The messenger relay feature additionally requires a separately running enigma_relay.py server.
Historical Enigma ciphers are not secure by modern standards. Use ENIGMA-X for learning and experimentation, not to protect real secrets.
