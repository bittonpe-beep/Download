# ENIGMA-X Download

**[Open the ENIGMA-X download site](https://enigma-x-download.onrender.com)**

You can also [download ENIGMA-X.pyw directly](./ENIGMA-X.pyw).

## Requirements
- Python 3
- Tkinter

The cipher features run locally. The messenger relay additionally needs a separately running `enigma_relay.py` server.

> Historical Enigma ciphers are not secure by modern standards. This project is for learning and experimentation, not protecting real secrets.
