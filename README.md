# ENIGMA-X Download

**[Open the ENIGMA-X download site](https://enigma-x-download.onrender.com)**

## One-download Windows package

Download **[ENIGMA-X-Portable.zip](https://github.com/bittonpe-beep/Download/releases/latest/download/ENIGMA-X-Portable.zip)**. It includes:
- ENIGMA-X desktop application
- Portable Python 3.12 runtime (Windows 64-bit)
- Tkinter and Tcl/Tk support
- `START-ENIGMA-X.bat` launcher

Extract the ZIP and double-click `START-ENIGMA-X.bat`. No separate Python installation is required.

The messenger relay additionally needs a separately running `enigma_relay.py` server.

> Historical Enigma ciphers are not secure by modern standards. This project is for learning and experimentation, not protecting real secrets.
